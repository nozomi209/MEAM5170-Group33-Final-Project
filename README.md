# MEAM5170 Group 33 Final Project

## 内容
- `report.pdf`：最终报告  
- `poster.pdf`：项目海报  
- 若干对比与基准图表（PDF）：letters A/L/O/R/T、trajectory comparison、neural safe planning benchmark  
- `index.html`：静态网站入口，含报告/海报预览与所有 PDF 链接

## 本地预览
```bash
python3 -m http.server 8000
# 然后浏览 http://localhost:8000
```

## 部署到 GitHub Pages
1. 推送到 `main` 分支（或 Pages 指定分支/目录）。  
2. 在仓库 Settings → Pages 中选择 `main` 分支（root）。  
3. 保存后稍等片刻，Pages 即可访问。
